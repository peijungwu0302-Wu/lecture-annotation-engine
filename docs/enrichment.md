# Enrichment

Enrichment has three independent controls:

- **Coverage = 100%:** evaluate every important Definition, Example, Result, Theorem, Proof, Exercise, and Figure.
- **Generation depth = unbounded:** create as many useful candidates as needed.
- **Visible density = constrained:** render only what page capacity and quality permit.

## Priority

Required candidates include definition intuition, example explanation, important omitted proof steps, and pedagogically useful exercise solutions. High-priority candidates include result meaning, derivations, and figure-reading guides. Tips, memory cues, common mistakes, and future-topic connections are optional.

Coverage is an evaluation promise, not a command to fill every blank area. The planner may drop optional candidates and should honor the CourseProfile whitespace-fill cap (normally 0.60-0.70).
