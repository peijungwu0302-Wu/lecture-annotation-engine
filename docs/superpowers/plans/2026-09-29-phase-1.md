# Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the Phase 1 contracts, synthetic demonstration, executable skeleton, and verification suite for Lecture Annotation Engine.

**Architecture:** A small Python package exposes independent semantic grouping, placement, and QA functions around two JSON Schema contracts. A deterministic ReportLab generator produces a fully synthetic source/annotated PDF pair, while documentation and a portable skill define the future pipeline without pretending Phase 1 is a production translator.

**Tech Stack:** Python 3.11+, standard library, jsonschema, PyYAML, pypdf, pdfplumber, reportlab, pytest, JSON Schema Draft 2020-12.

**Spec:** `docs/specification-v1.md`

## Global Constraints

- Never commit or redistribute the reference lecture PDF or derivatives of its content.
- Preserve source ink by default and preserve page count unless explicitly requested.
- Translation and annotation target font is 7-8 pt; minimum is 5.5 pt.
- Enrichment coverage is 100%, generation depth is unbounded, and visible density is constrained.
- Margin roles are CourseProfile data, never global assumptions.
- Phase 1 provides honest skeletons, not a production-complete translation engine.

## Review Focus

- Invalid or out-of-page bounding boxes must be rejected by schema validation.
- Translation records must reference logical source blocks and declare math-normalized state.
- Placement must never accept overlap with immutable source ink.
- Tiny-font QA must distinguish target-sized content from content below 5.5 pt.
- Synthetic output must retain page count and page size without containing protected sample content.
